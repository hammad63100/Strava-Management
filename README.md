# Strava Management

Welcome to **Strava Management** - We are brand activists. With 60+ brand activists dedicated to serving brands, this project serves as our central hub.

## Tech Stack

This project is built with:

- [Next.js](https://nextjs.org/) (App Router)
- [React](https://reactjs.org/)
- [Agentation](https://agentation.com/)

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `app/`: Next.js App Router files.
- `components/`: Reusable React components (Navbar, AgentationProvider, etc.).
- `public/`: Static assets.
